# 第三方访问令牌生成接口开发文档

## 1. 接口概述
本接口用于生成第三方系统访问业务接口所需的认证令牌。第三方系统需提供预共享的应用ID和签名信息，验证通过后将返回一个JWT格式的访问令牌，该令牌可用于后续业务接口的访问认证。

## 2. 基本信息
- **接口路径**: `/api/v1/third-party/token`
- **请求方法**: GET
- **认证方式**: Header签名验证
- **响应格式**: application/json

## 3. 请求参数

### 3.1 请求头
| 参数名 | 必填 | 说明 |
| ------ | ---- | ---- |
| token | 是 | 格式: `appId-{appId}#timestamp-{timestamp}#sign-{sign}` |

**参数说明**:
- `appId`: 应用ID，示例: aihear
- `timestamp`: 当前时间戳(毫秒)，示例: 1732155863597
- `sign`: 签名值，计算规则: `md5(appId + appsecret + timestamp)`

**签名计算示例**:
```python
import hashlib
import time

appId = "aihear"
appsecret = "z88zJsQ!rc4DOkMTKnfokU3fHOxFeZzoYvwGvHyG@r1"
timestamp = str(int(time.time() * 1000))

# 拼接字符串并计算MD5
sign_str = appId + appsecret + timestamp
sign = hashlib.md5(sign_str.encode()).hexdigest()

# 最终header token值
header_token = f"appId-{appId}#timestamp-{timestamp}#sign-{sign}"
```

## 4. 响应参数

### 4.1 成功响应 (HTTP 200)
```json
{
  "code": 200,
  "message": "成功",
  "data": {
    "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "token_type": "Bearer",
    "expires_in": 3600,
    "scope": "api"
  }
}
```

### 4.2 失败响应
**签名验证失败 (HTTP 401)**
```json
{
  "code": 401,
  "message": "无效的签名",
  "data": null
}
```

**请求超时 (HTTP 401)**
```json
{
  "code": 401,
  "message": "请求已过期",
  "data": null
}
```

**无效应用ID (HTTP 403)**
```json
{
  "code": 403,
  "message": "无效的应用ID",
  "data": null
}
```

## 5. 验证规则
1. **时间窗口验证**: 接收请求时验证timestamp，仅接受5分钟(300秒)内的请求
2. **签名验证**: 服务端使用相同的算法重新计算sign，与请求中的sign比对
3. **应用ID验证**: 验证appId是否为已注册的有效应用ID

## 6. FastAPI实现示例

```python
from fastapi import FastAPI, Depends, HTTPException, Header
from fastapi.security import HTTPBearer, HTTPAuthorizationCredentials
from datetime import datetime, timedelta
import hashlib
import jwt
import time
import re
from pydantic import BaseModel

app = FastAPI()
security = HTTPBearer()

# 配置
APP_ID = # 从环境变量获取
APP_SECRET = "z88zJsQ!rc4DOkMTKnfokU3fHOxFeZzoYvwGvHyG@r1"  # 从环境变量获取
JWT_SECRET_KEY = "your_strong_jwt_secret_key"  # 从环境变量获取
JWT_ALGORITHM = "HS256"
ACCESS_TOKEN_EXPIRE_MINUTES = 1440 # 1天
TIMESTAMP_VALID_WINDOW = 300  # 5分钟有效窗口，单位秒

class TokenResponse(BaseModel):
    access_token: str
    token_type: str
    expires_in: int
    scope: str

def verify_third_party_token(token: str = Header(..., alias="token")):
    """验证第三方请求的签名token"""
    # 解析token格式
    pattern = r"appId-(.*?)#timestamp-(\d+)#sign-([a-fA-F0-9]{32})"
    match = re.match(pattern, token)
    
    if not match:
        raise HTTPException(
            status_code=401,
            detail="无效的token格式"
        )
    
    app_id, timestamp_str, sign = match.groups()
    timestamp = int(timestamp_str)
    
    # 验证应用ID
    if app_id != APP_ID:
        raise HTTPException(
            status_code=403,
            detail="无效的应用ID"
        )
    
    # 验证时间戳是否在有效窗口内
    current_timestamp = int(time.time() * 1000)
    time_diff = abs(current_timestamp - timestamp) / 1000  # 转换为秒
    
    if time_diff > TIMESTAMP_VALID_WINDOW:
        raise HTTPException(
            status_code=401,
            detail="请求已过期"
        )
    
    # 验证签名
    sign_str = app_id + APP_SECRET + str(timestamp)
    expected_sign = hashlib.md5(sign_str.encode()).hexdigest()
    
    if sign != expected_sign:
        raise HTTPException(
            status_code=401,
            detail="无效的签名"
        )
    
    return {"app_id": app_id}

@app.get("/api/v1/third-party/token", response_model=TokenResponse)
async def generate_third_party_token(token_data: dict = Depends(verify_third_party_token)):
    """生成第三方访问令牌"""
    # 创建JWT payload
    expire = datetime.utcnow() + timedelta(minutes=ACCESS_TOKEN_EXPIRE_MINUTES)
    payload = {
        "sub": token_data["app_id"],
        "type": "third_party",
        "exp": expire,
        "iat": datetime.utcnow(),
        "scope": "api"
    }
    
    # 生成JWT令牌
    access_token = jwt.encode(
        payload, 
        JWT_SECRET_KEY, 
        algorithm=JWT_ALGORITHM
    )
    
    return TokenResponse(
        access_token=access_token,
        token_type="Bearer",
        expires_in=ACCESS_TOKEN_EXPIRE_MINUTES * 60,  # 转换为秒
        scope="api"
    )
```

## 7. 安全注意事项
1. **密钥管理**: APP_SECRET和JWT_SECRET_KEY不应硬编码在代码中，应通过环境变量或密钥管理系统注入
2. **时间窗口**: 设置合理的时间窗口(当前为5分钟)可防止重放攻击
3. **令牌有效期**: 生成的access_token应设置合理的过期时间(当前为1天)

## 8. 测试示例
```bash
# 生成签名
APP_ID="aihear"
APP_SECRET="z88zJsQ!rc4DOkMTKnfokU3fHOxFeZzoYvwGvHyG@r1"
TIMESTAMP=$(date +%s%3N)
SIGN=$(echo -n "${APP_ID}${APP_SECRET}${TIMESTAMP}" | md5sum | awk '{print $1}')

# 发起请求
curl -X GET "http://your-api-domain/api/v1/third-party/token" \
  -H "token: appId-${APP_ID}#timestamp-${TIMESTAMP}#sign-${SIGN}"
```

## 9. 后续使用
获取到access_token后，第三方系统在访问业务接口时，需在请求头中携带该令牌:
```
Authorization: Bearer <access_token>
```
